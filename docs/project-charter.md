# Project charter

## Purpose

Demonstrate test-driven API development with ASP.NET Core, `HttpClient` abstraction, mock-based unit tests, configuration binding, health checks, OpenAPI, and Docker packaging.

## Current scope

- A users endpoint backed by a configured external sample-data API.
- Service abstraction and dependency injection for HTTP access.
- xUnit/Moq/FluentAssertions unit-test fixtures.
- Swagger/health endpoints and Docker/Compose assets.

## Portfolio decision

Retain as a learning/reference repository pending archive review. Consolidate its lessons into primary .NET/Docker showcases rather than featuring it independently.

## Outside current scope

- Ownership of user data, persistent storage, authentication, production integrations, or service operations.
- CI/CD, production container configuration, observability, and externally supported deployment.
