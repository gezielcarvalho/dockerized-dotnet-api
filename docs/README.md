## Status

This repository is a focused .NET 8 practice API: it uses an external sample-data endpoint, a service abstraction, mocked-HTTP unit tests, health/Swagger configuration, and Docker assets. It is useful reference material but overlaps more substantial .NET portfolio projects and should not be promoted as a separate showcase.
